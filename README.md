# MessagePorter

This repository contains example TypeScript interfaces that model a Human Resources (HR) platform. The interfaces cover employee self-service, manager workflows and authentication pieces. They are provided as a starting point for building the frontend or backend of the system described in the specifications.

All TypeScript definitions are located in `src/interfaces.ts`.

The file includes:

- Employee profile and documents
- Leave requests and balances
- Expense reports
- Training catalogue entries and progress
- Knowledge base articles and news posts
- Performance goals and evaluations
- Team KPIs and project assignments
- Basic authentication token structures

These interfaces can be imported in a React or Node.js project to bootstrap the data models of the HR application.
